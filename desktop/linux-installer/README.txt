Krutrim Mulyankan — Linux setup

1. Extract this archive in Files.
2. Open “Install Krutrim Mulyankan”.
3. Click “Install & Open”.

No terminal commands or administrator password are needed. Setup works offline
and adds Krutrim Mulyankan to your application menu. You may delete this folder
after installing.

To remove the app, open setup again and click “Remove”, or use the application
menu's “Manage installation” action. Evaluation results and saved keys are kept.

This download is for Linux x86_64 with GTK 3 (including Omarchy, Ubuntu 22.04+
and Fedora). The application runs without FUSE. A graphical desktop session
and permission to run applications in your home folder are required.
